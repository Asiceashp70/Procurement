# ทดสอบระบบ ZenHere

## เปิดระบบ

**Windows:** ต้องมี [Node.js 22 LTS](https://nodejs.org) และ [Docker Desktop](https://www.docker.com/products/docker-desktop/) (เปิดไว้)
แล้วดับเบิลคลิก **`start-test.bat`** ในโฟลเดอร์ `zenhere`

**macOS / Linux:** `./start-test.sh`

สคริปต์จะ
1. เปิด PostgreSQL ใน Docker (port 5436 ไม่ชนกับระบบเดิมที่ใช้ 5435)
2. สร้าง `backend/.env` สำหรับทดสอบ (ถ้ายังไม่มี)
3. ติดตั้งและ build (ครั้งแรกใช้เวลาไม่กี่นาที)
4. ใส่ข้อมูลตัวอย่าง (ครั้งต่อไปจะข้าม ถ้ามีอยู่แล้ว)
5. เปิด API และเว็บ แล้วเปิดเบราว์เซอร์ที่ http://localhost:5173

เริ่มใหม่ด้วยข้อมูลตัวอย่างชุดใหม่: **`reset-test.bat`** (ลบข้อมูลทดสอบทั้งหมด)

> ไม่มี Docker: ติดตั้ง PostgreSQL 16 เอง สร้าง user/database `zenhere` แล้วแก้ `DATABASE_URL` ใน `backend/.env`

### ทดสอบบนมือถือ
มือถือต่อ Wi-Fi เดียวกับคอมพิวเตอร์ แล้วเปิดที่อยู่ "Network" ที่แสดงในหน้าต่าง **ZenHere Web** เช่น `http://192.168.1.20:5173`
(ถ้าเปิดไม่ได้ ให้อนุญาต Node.js ใน Windows Firewall) ลองวาดลายเซ็นด้วยนิ้ว ถ่ายรูปลายเซ็นบนกระดาษ และเซ็นเอกสารบนจอเล็ก

## ใช้งานระหว่างทดสอบ

| ของจริง | ตอนทดสอบ |
|---|---|
| เข้าสู่ระบบ | กดเลือกบัญชีทดลองในหน้า login หรือ "+ ผู้ใช้ใหม่" เพื่อลองลงทะเบียนครั้งแรก |
| ข้อความแจ้งเตือนเข้ามือถือ | เมนู **🔔 แจ้งเตือน (ทดสอบ)** มุมขวาบน (ตัวเลขสีแดง = ข้อความใหม่) ปุ่มในการ์ดพาไปหน้าเดียวกับปุ่มในข้อความแจ้งเตือนจริง |
| เปิดลิงก์จากข้อความแจ้งเตือนของแต่ละคน | เมนู **สลับ ▾** มุมขวาบน สลับเป็นอีกคนได้ทันที |
| ระบบตรวจการเตือนตามเวลา ทุก 5 นาที | Super Admin กด "⏱ รันการเตือนตามเวลาตอนนี้" ในหน้าแจ้งเตือน (ทดสอบ) |

## บัญชีทดลอง

| บัญชี | บทบาท | มีอะไรรออยู่ |
|---|---|---|
| ธวัช ผู้ดูแลระบบ | Super Admin + ผู้ดูแลบริษัท | หลังบ้าน Super Admin, ใบรับรอง, log ระบบ |
| มาลี ใจดี | ผู้ดูแลบริษัท (ฝ่ายบุคคล) | ผู้ส่งสัญญาจ้างและประกาศ, ร่าง "แบบฟอร์มใบลา" รอวางกรอบ, คำขอเข้าร่วมของน้องใหม่ |
| วิชัย มั่นคง | ผู้จัดการ สร้างเอกสารได้ ใช้ตราบริษัทได้ | เซ็นสัญญาจ้างต่อจากสมชาย (ลายเซ็น + ตรา) |
| สมชาย รักงาน | พนักงาน | สัญญาจ้างรอเซ็น (ลายเซ็น วันที่ เลขบัตรประชาชน checkbox) |
| สมหญิง ตั้งใจ | พนักงาน **ยังไม่เปิดรับการแจ้งเตือน** | ประกาศวันหยุดครบกำหนดพรุ่งนี้ |
| น้องใหม่ เพิ่งมา | รออนุมัติ | ยังใช้งานไม่ได้จนกว่ามาลีจะอนุมัติ |

บริษัท "บริษัท ทดลองระบบ จำกัด" มีใบรับรองดิจิทัล**ทดลอง** (self-signed รหัสผ่าน `demo1234`) ไฟล์ที่ซีลจึงตรวจได้ว่าไม่ถูกแก้
แต่ Adobe Reader จะแจ้งว่า "ไม่รู้จักผู้ออกใบรับรอง" ซึ่งเป็นเรื่องปกติของใบทดลอง

## สถานการณ์ที่ควรลอง

**ลงทะเบียนและเข้าร่วมบริษัท**
- [ ] "+ ผู้ใช้ใหม่" → กรอกข้อมูล → วาดลายเซ็น หรือถ่ายรูปลายเซ็นบนกระดาษขาว (ลองเลื่อนความไว สีหมึก หมุน) → ยินยอม PDPA
- [ ] เป็นมาลี → หลังบ้านบริษัท → ลิงก์เชิญ (คัดลอกรหัส 8 หลักหรือลิงก์) → สลับกลับเป็นผู้ใช้ใหม่ → เข้าร่วมบริษัท
- [ ] มาลีอนุมัติ/ปฏิเสธ (ต้องใส่เหตุผล) → ผู้ใช้ใหม่เห็นผลใน 🔔 แจ้งเตือน (ทดสอบ)
- [ ] นำเข้ารายชื่อจาก Excel/CSV แล้วสมัครด้วยรหัสพนักงานและเบอร์ที่ตรงกัน → อนุมัติให้เอง

**เซ็นเอกสาร**
- [ ] เป็นสมชาย → 🔔 แจ้งเตือน (ทดสอบ) → "เปิดเพื่อเซ็น" → ลองกดยืนยันทั้งที่ยังกรอกไม่ครบ (ระบบเลื่อนไปช่องที่ขาด) → กรอกครบแล้วเซ็น
- [ ] เป็นวิชัย → ได้ข้อความ "ถึงลำดับ" → ประทับตรา + เซ็น → เอกสารเซ็นครบ
- [ ] เป็นมาลี → ได้ "เอกสารเซ็นครบแล้ว" → ดาวน์โหลดไฟล์ฉบับสมบูรณ์ (มีหน้าใบรับรองท้ายไฟล์) → หน้า "ตรวจสอบไฟล์" ลองอัปโหลดไฟล์นี้ และไฟล์ที่แก้แล้ว
- [ ] ลองปฏิเสธการเซ็น, เตือนซ้ำ (ได้ชั่วโมงละครั้ง), ยกเลิกเอกสาร, Admin เปลี่ยนตัวผู้เซ็น
- [ ] ลองเซ็นข้ามลำดับ (เปิดลิงก์ของคนที่ยังไม่ถึงลำดับ) → ระบบไม่ให้เซ็น

**สร้างเอกสาร**
- [ ] เป็นมาลี → เอกสาร → ร่าง "แบบฟอร์มใบลา" → เพิ่มผู้เซ็น → เลือกชนิดช่องแล้วแตะบนหน้าเพื่อวาง → ลาก/ย่อขยาย → ตั้งวันครบกำหนด → ส่ง
- [ ] อัปโหลด PDF ของบริษัทเองหรือรูปถ่ายเอกสาร ลองช่อง "สำเนาถูกต้อง" แบบวางทุกหน้า

**หลังบ้านและค้นหา**
- [ ] หน้าภาพรวมของบริษัท (เลขทุกตัวกดเข้าไปดูรายการได้), ตราประทับ, log ผู้ดูแล
- [ ] ค้นหา "สัญญาจ้าง", "ค่าจ้าง", "วันหยุด" → กดผลค้นแล้วเปิดหน้าที่เจอพร้อมไฮไลต์
- [ ] เป็นสมหญิง → เห็นว่าเอกสารใกล้ครบกำหนด / ในหน้าเอกสารฝั่งผู้ส่งขึ้นว่า "ยังไม่เปิดรับการแจ้งเตือน"
- [ ] เป็นธวัช → 🔔 แจ้งเตือน (ทดสอบ) → "รันการเตือนตามเวลาตอนนี้" → สมหญิงได้ข้อความใกล้ครบกำหนด

ถ้าเจอปัญหา ส่งภาพหน้าจอและบอกว่าเป็นบัญชีไหน ทำอะไรอยู่ หรือแนบข้อความจากหน้าต่าง **ZenHere API**
